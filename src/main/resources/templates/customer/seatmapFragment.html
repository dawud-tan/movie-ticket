{! Auto-refreshing availability by polling the fragment endpoint the manual button already uses. Deliberately polling rather than push: push reduces cost at high concurrency, and it is not what makes the map live. Three details this depends on, none of them incidental: 1. hx-select="#seat-grid" with hx-target="this" means ONLY the grid is swapped, even though the endpoint returns this whole fragment. That is what keeps the customer's typed name and phone — and any error banner above — outside the replaced region. Swapping #seat-map-container every 3s would clear the form mid-entry and make booking effectively impossible. 2. seatmap-selection.js cancels the request while the tab is hidden. htmx keeps the timer running and the fetch is skipped, so there is no network or database work for a backgrounded tab, and it fires one immediate refresh when the tab is shown again, because returning to a stale map is exactly when accuracy matters most. Not a trigger filter ([document.visibilityState === 'visible'], as it was until 2026-11-01): htmx compiles a filter with Function, which the page's Content-Security-Policy refuses, and htmx 2.0.10 does not catch that, so the grid's triggers would never be set up. 3. hx-trigger is set explicitly, which also stops the div's default click trigger from firing a request every time someone picks a seat. 4. seat-availability-changed is fired by seatmap-push.js when a push arrives, so a notification refreshes the grid immediately instead of waiting up to 3s for the next poll. Push is the latency improvement here; polling remains the mechanism, so the map still works with notifications denied, on iOS in a plain tab, or with no Firebase credentials configured at all. "every 3s" above is the safe default rendered here on every response — including every poll's own swap — and is what every visitor gets until seatmap-push.js confirms a live subscription. Once confirmed, that script rewrites #seat-grid's hx-trigger to "every 30s" on each freshly swapped-in grid (push then carries normal-latency updates instead), and puts it back the moment the subscription is known stale. This template only ever emits the 3s form; see seatmap-push.js for why the interval otherwise seen in the DOM can differ. !}
